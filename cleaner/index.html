One command away.

Install Cleaner from the its-ash Homebrew tap.

Terminal
# Add the tap (once)
$ brew tap its-ash/tap
# Trust the tap (once, for unsigned casks)
$ brew trust its-ash/tap
# Install Cleaner
$ brew install --cask cleaner
# Exempt from macOS Gatekeeper
$ xattr -cr /Applications/Cleaner.app

Open Cleaner from Applications, add your project folders in Settings, then press ⌘R to scan.
