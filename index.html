Nodio

Voice to text, on your Mac

Hold a key, speak, release — your words land in any text field. On-device Whisper, zero cloud, no subscriptions.

  • On-device Whisper (Indian English + Hinglish)
  • Voice commands: punctuation, delete, snippets
  • Per-app styles: casual, formal, code-safe
  • Floating HUD with live waveform
  • History, stats & custom vocabulary
  • Requires macOS 13.3+ (Ventura)

Router

Native macOS AI routing client

A local OpenAI-compatible proxy that routes requests across NVIDIA, OpenRouter, Cloudflare, Groq, Ollama, and Hugging Face — with automatic fallback and model discovery.

  • Multi-provider routing with automatic fallback
  • OpenAI-compatible API (port 9694)
  • Model discovery & capability detection
  • Token usage & request activity log
  • Menu-bar app with zero-config setup
  • Requires macOS 15.0+ (Sequoia)
